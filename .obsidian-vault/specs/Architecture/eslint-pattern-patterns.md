# ESLint Pattern Patterns

## Definition

ESLint Pattern Patterns are **design patterns for working with ESLint architecture**.

> "ESLint is a pluggable linting utility for JavaScript and TypeScript, enforcing code quality and consistency." — ESLint

## Problem Addressed

Without ESLint pattern patterns:
- **Quality**: Code quality is poor and inconsistent
- **Style**: Code style is inconsistent
- **Testing**: Hard to test code
- **Maintenance**: Hard to maintain code

## Scope and Boundaries

- ESLint Pattern Patterns ≠ ESLint (ESLint pattern patterns are patterns, ESLint is a commit management pattern)
- ESLint Pattern Patterns = CI/CD (ESLint pattern patterns are patterns, CI/CD is a DevOps pattern)
- ESLint Pattern Patterns is a **patterns**, not a commit management pattern

## When to Apply

- When building applications
- when code quality matters
- when testing is important
- when maintenance is important

## Tradeoffs and When to Avoid

| Cost | Description |
|------|-------------|
| **Complexity** — ESLint pattern patterns are complex |
| **Time** — ESLint pattern patterns take time |
| **Over-ESLint** — Don't use ESLint for everything |

## Common Misuses

- **Everything ESLint**: Not everything needs ESLint pattern patterns
- **Confusing with CI/CD**: ESLint pattern patterns ≠ CI/CD
- **Over-ESLint**: Too much ESLint creates complexity
