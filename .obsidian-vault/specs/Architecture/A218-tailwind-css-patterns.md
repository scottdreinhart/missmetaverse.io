# Tailwind CSS Patterns

## Definition

Tailwind CSS Patterns are **design patterns for working with Tailwind CSS for styling web applications**.

> "Tailwind CSS is a utility-first CSS framework for rapidly building custom user interfaces." — Tailwind CSS Docs

## Problem Addressed

Without Tailwind CSS patterns:
- **Consistency**: Styling is inconsistent
- **Duplication**: CSS is duplicated
- **Maintenance**: Hard to maintain CSS
- **Performance**: Performance is poor

## Scope and Boundaries

- Tailwind CSS Patterns ≠ Tailwind CSS (Tailwind CSS patterns are patterns, Tailwind CSS is a framework)
- Tailwind CSS Patterns ≠ CSS (Tailwind CSS patterns are patterns, CSS is a language)
- Tailwind CSS Patterns is a **patterns**, not a framework

## When to Apply

- When building web applications
- when consistency matters
- when maintenance is important
- when performance is important

## Tradeoffs and When to Avoid

| Cost | Description |
|------|-------------|
| **Complexity** — Tailwind CSS patterns are complex |
| **Time** — Tailwind CSS patterns take time |
| **Over-Tailwind** — Don't use Tailwind for everything |

## Common Misuses

- **Everything Tailwind**: Not everything needs Tailwind CSS patterns
- **Confusing with Tailwind CSS**: Tailwind CSS patterns ≠ Tailwind CSS
- **Over-Tailwind**: Too much Tailwind creates complexity
