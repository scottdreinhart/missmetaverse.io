# Husky Pattern Patterns

## Definition

Husky Pattern Patterns are **design patterns for working with Husky architecture**.

> "Husky enables Git hooks in Node.js projects, allowing pre-commit and other hook-based automation." — Husky

## Problem Addressed

Without Husky pattern patterns:
- **Quality**: Code quality is poor and inconsistent
- **Commit hygiene**: Commits are inconsistent
- **Testing**: Hard to test commits
- **Maintenance**: Hard to maintain commits

## Scope and Boundaries

- Husky Pattern Patterns ≠ Husky (Husky pattern patterns are patterns, Husky is a commit management pattern)
- Husky Pattern Patterns = ESLint (Husky pattern patterns are patterns, ESLint is a commit management pattern)
- Husky Pattern Patterns is a **patterns**, not a commit management pattern

## When to Apply

- When building applications
- when commit hygiene matters
- when testing is important
- when maintenance is important

## Tradeoffs and When to Avoid

| Cost | Description |
|------|-------------|
| **Complexity** — Husky pattern patterns are complex |
| **Time** — Husky pattern patterns take time |
| **Over-Husky** — Don't use Husky for everything |

## Common Misuses

- **Everything Husky**: Not everything needs Husky pattern patterns
- **Confusing with ESLint**: Husky pattern patterns ≠ ESLint
- **Over-Husky**: Too much Husky creates complexity
