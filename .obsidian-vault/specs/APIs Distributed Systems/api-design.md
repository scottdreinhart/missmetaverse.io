## Definition

API Design is the practice of creating well-structured, intuitive, and maintainable APIs following best practices for REST, GraphQL, and other API paradigms.

## Problem Addressed

Without API Design:
- APIs are confusing
- Integration is difficult
- Maintenance is hard
- User experience is poor

## Scope of Boundaries

API Design applies to:
- REST API design
- GraphQL API design
- API best practices
- API documentation

API Design does not apply to:
- Backend code
- Database design
- Infrastructure
- Testing

## When to Apply

- Building APIs
- Needing good design
- Wanting best practices
- Documenting APIs

## Tradeoffs and When to Avoid

- **Complexity**: API Design adds complexity
- **Not for simple apps**: Simple apps may not need API Design
- **Not for internal**: Internal apps may not need API Design
- **Not for all**: Not all apps need API Design

## Implementation Guidance

1. **Define endpoints**: Define API endpoints
2. **Use standards**: Use REST/GraphQL standards
3. **Document**: Document API
4. **Version**: Version API
5. **Test**: Test API

## Common Misuses

- **Not defining**: Not defining endpoints
- **Not using**: Not using standards
