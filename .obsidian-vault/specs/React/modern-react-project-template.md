## Definition

Modern React Project Template is a recommended project structure and set of conventions for React applications, including folder organization, file naming, and architectural patterns.

## Problem Addressed

Without project template:
- Project structure is inconsistent
- Team onboarding is difficult
- Code organization is unclear
- Maintenance is error-prone

## Scope and Boundaries

Project template applies to:
- React project structure
- Folder organization
- File naming conventions
- Architectural patterns

Project template does not apply to:
- Backend code
- Database design
- Infrastructure
- Build configuration

## When to Apply

- Starting new React projects
- Onboarding new team members
- Standardizing project structure
- Improving code organization

## Tradeoffs and When to Avoid

- **Over-constraining**: Too many rules restrict flexibility
- **Not for simple projects**: Simple projects don't need full template
- **Not for prototypes**: Prototypes don't need full template
- **Not for backend**: Backend code is different

## Implementation Guidance

1. **Create structure**: Create recommended folder structure
2. **Follow conventions**: Follow file naming conventions
3. **Use patterns**: Use architectural patterns
4. **Document**: Document project structure
5. **Enforce**: Enforce conventions through linting
