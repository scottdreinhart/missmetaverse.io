# Purpose

Note templates: reusable structures for specs, ADRs, bug reports, retrospectives, and daily notes.

# Ownership

- Owner: project team
- Scope: all content under `.obsidian-vault/specs/templates/`

# Local Contracts

- File naming: kebab-case with `-template` suffix (e.g., `adr-template.md`)
- Templates are not content — they are intentionally orphaned (no inbound links needed)
- Templates have `slug:` but may not have `sources:` or `tags:`

# Work Guidance

- New templates go here
- Templates are referenced by name, not by wikilink
- Update templates when vault conventions change

# Verification

- Templates are intentionally orphan files — no broken links expected

None. This is a leaf domain.
