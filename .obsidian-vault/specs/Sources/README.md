## How Sources Work

Each source note contains:
- `source_id` — Stable identifier
- `title` — Source title
- `author` or `organization`
- `source_type` — documentation | specification | book | article | standard
- `canonical_url` — Full URL
- `publication_date` — When verified
- `accessed_on` — When retrieved
- `verification_status` — verified | partial | unverified
- `relevant_sections` — What was actually inspected
- `claims_supported` — Which concept claims this source supports
- `access_limitations` — Paywall, rate limits, etc.
- `research_notes` — Context about the retrieval

Sources are linked from concept notes using the format:
`[[Sources/<source-slug>|<source-slug>]]`
