## Definition

@axe-core/react Accessibility is the setup and configuration of @axe-core/react for accessibility testing in React applications, including WCAG compliance and accessibility monitoring.

## Problem Addressed

Without @axe-core/react:
- Accessibility is not tested
- WCAG compliance is unknown
- Accessibility issues are missed
- Accessibility monitoring is difficult

## Scope of Boundaries

@axe-core/react applies to:
- Accessibility testing
- WCAG compliance
- Accessibility monitoring
- Accessibility issues

@axe-core/react does not apply to:
- Backend code
- Database design
- Infrastructure
- Testing

## When to Apply

- Building React applications
- Needing accessibility testing
- Wanting WCAG compliance
- Needing accessibility monitoring

## Tradeoffs and When to Avoid

- **Not for simple apps**: Simple apps don't need @axe-core/react
- **Not for backend**: @axe-core/react is for frontend only
- **Not for non-React**: @axe-core/react is for React only
- **Not for SSR**: SSR requires additional configuration
