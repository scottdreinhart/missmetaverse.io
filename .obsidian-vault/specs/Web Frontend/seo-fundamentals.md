## Definition

SEO Fundamentals are the principles and techniques for optimizing web content for search engines, including meta tags, structured data, and content optimization.

## Problem Addressed

Without SEO Fundamentals:
- Content is not discoverable
- Traffic is low
- Rankings are poor
- Visibility is limited

## Scope of Boundaries

SEO Fundamentals applies to:
- Search engine optimization
- Meta tags
- Structured data
- Content optimization

SEO Fundamentals does not apply to:
- Backend code
- Database design
- Infrastructure
- Testing

## When to Apply

- Building web apps
- Needing discoverability
- Wanting better rankings
- Optimizing content

## Tradeoffs and When to Avoid

- **Complexity**: SEO Fundamentals adds complexity
- **Not for internal**: Internal apps don't need SEO Fundamentals
- **Not for APIs**: APIs don't need SEO Fundamentals
- **Not for all**: Not all apps need SEO Fundamentals
